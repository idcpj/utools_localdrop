🔥 LocalDrop —— 极速、优雅、安全的局域网与公网多端文件互传利器！

厌倦了传大文件要经过慢吞吞的微信QQ压缩、满速网盘还要会员、或是为了把视频传给手机到处找数据线？
LocalDrop 基于轻量本地 HTTP 引擎与现代化 Raycast 暗黑设计，让文件跨设备共享如呼吸般自然顺畅！

✨【核心功能亮点】

1. 🚀 跑满内网带宽，极速直连
无需经过任何第三方中转服务器，局域网千兆/百兆内网全速传输，几十 GB 的大文件与视频轻松秒传，完全不耗费外网流量。

2. 📱 免装客户端，扫码即开即用
接收端（手机/iPad/安卓/Mac/Windows/Linux）无需安装任何第三方 App 或插件！扫描屏幕上的二维码，即可在手机浏览器中直接浏览、预览文本与下载文件。

3. 📁 丰富分享类型，原生目录浏览
- 支持单文件、多文件批量分享；
- 原生支持「整目录文件夹」分享！对方可在浏览器中逐级展开目录树无缝下载，无需提前压缩打包为 zip；
- 支持常用代码、剪贴板纯文本快速共享与一键复制。

4. 💻 终端与开发者友好直链
每个文件均配有独立的极速直链与专属下载 Token，支持一键复制 `wget` / `curl` 命令行，开发机与无界面 Linux 服务器拉取文件一步到位。

5. 🌐 临时公网穿透（Cloudflare Tunnel）
好友不在同一个 WiFi 下？内置一键公网临时穿透通道，免公网 IP、免路由器端口映射，安全将大文件分享给异地远程好友。

6. 🔒 严密的安全防护与隐私设计
- 统一访问密码保护，哈希安全校验，拒绝陌生人偷窥；
- 支持网页端文件反向回传上传（默认关闭，按需开启并隔离存储于专用目录）；
- 纯本地运行，不上传任何用户元数据，随 uTools 启停，关闭即销毁所有访问通道。

--------------------------------------------------------------------------------
💡【快速上手使用指南】

• 快速呼出：在 uTools 搜索框输入「局域网分享」或「localdrop」
• 快捷触发：在文件管理器中右键选中文件或文件夹，呼出 uTools 选择「分享文件或文件夹」
• 文本速传：选中文本呼出 uTools 选择「分享选中文本」即可一键生成局域网分享卡片

--------------------------------------------------------------------------------
❓【常见问题解答 FAQ】

Q1：接收端需要安装 uTools 吗？
A：完全不需要！对方只需在手机或电脑浏览器中打开你提供的局域网链接，或直接用微信/相机扫码即可直接使用。

Q2：为什么服务关闭后别人无法下载了？
A：为了最大程度保障安全与省电，LocalDrop 为随用随启设计。当退出 uTools 或手动在设置中停止服务时，所有网络端口均会彻底关闭。

Q3：公网穿透需要付费或额外安装工具吗？
A：无需付费！内置了 Cloudflare Quick Tunnel 临时通道，首次开启自动适配运行，开箱即用。
