【首发发布】LocalDrop · 局域网与公网极速分享利器 V1.0.0 正式上线！

告别数据线与繁琐的传输助手，打造最优雅、极速的多端文件互传体验：

【核心特性】
1. 🚀 局域网极速直连：跑满千兆/百兆内网带宽，大文件传输秒传，不耗外网流量。
2. 📱 跨端免装客户端：手机/平板/电脑浏览器扫码即开即下，开箱即用。
3. 📁 丰富分享类型：原生支持单个文件、批量文件、整目录文件夹以及剪贴板纯文本。
4. 🌲 文件夹层级浏览：支持多层级目录在线浏览与单文件按需下载，无需提前打包压缩。
5. ⚡ 开发者友好直链：一键生成带鉴权 Token 的下载直链，支持 wget / curl 终端高速拉取。
6. 🌐 临时公网穿透：内置 Cloudflare Quick Tunnel 穿透通道，异地也能安全将文件分享给好友。
7. 🔒 端到端安全保护：全站统一哈希访问密码防护、防路径穿越、上传目录隔离、随 uTools 即开即关不留后台隐患。
8. 🎨 现代暗黑美学：沉浸式 Raycast 风格设计，轻盈流畅。

## 📝 详细更新日志 (Changelog)

### [1.0.0] - 2026-09-28 (首个正式版发布)

#### 🎉 新增功能 (Features)
- **多方式一键分享**：
  - 支持通过输入框手动选择文件、文件夹或输入文本创建分享。
  - 支持从桌面或文件管理器右键直接呼出 uTools 进行「分享文件或文件夹」。
  - 支持任意界面选中文字后呼出 uTools 进行「分享选中文本」。
- **内网极速 HTTP 服务**：
  - 本地轻量 Node.js HTTP 引擎，随 uTools 启动与关闭，纯本地运行无外网依赖。
  - 智能识别与切换可用局域网 IPv4 网卡地址，自动分配端口并具备端口冲突自适应防护。
- **全平台自适应 Web 站点**：
  - 内置深色/暗黑主题响应式 Web 端，手机端、iPad端及电脑浏览器体验一致。
  - 文件夹支持动态树状结构/平铺目录浏览，单文件秒速下载。
  - 分享文本支持在线高亮预览与一键复制。
- **终端与开发者工具链直连**：
  - 列表中每个文件均可一键复制带一次性/安全 Token 的下载直链。
  - 原生支持提供 `curl -OJ <URL>` 和 `wget <URL>` 下载命令，方便远程服务器或无界面终端下载。
- **公网穿透分享 (Cloudflare Quick Tunnel)**：
  - 在需要异地互传时，支持一键建立临时 Cloudflare 公网隧道，无需公网 IP、无需路由配置。
  - 强制绑定访问密码验证，公网下载使用独立安全令牌，保障外网传输安全。
- **文件回传上传能力**：
  - 支持网页端向宿主机反向上传文件（默认关闭，需用户在设置中显式开启）。
  - 所有上传文件严格限制在专用 `uploads` 隔离目录，防止路径穿越和文件覆盖。
- **安全与权限控制**：
  - 访问控制：全站统一密码访问认证，哈希存储不存明文。
  - 防暴力破解：限制错误尝试频率，防越权防护。
  - 原始数据安全：仅读取分享原路径，不复制、不修改用户源文件。
