## 💡 截图建议提示

1. **尺寸规范**：推荐分辨率统一为 `1280x800` 或 `1920x1080`，格式为 `PNG`。
2. **生成方式**：
   - 可以在浏览器中打开本地服务（例如 `http://127.0.0.1:5178/` 和 `http://127.0.0.1:5178/site.html`），使用浏览器开发者工具模拟对应分辨率截取。
   - 使用统一的外边框、暗黑圆角与文字说明包装，视觉效果更佳。
