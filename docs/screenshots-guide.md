# uTools 插件应用截图规划与规范 (Screenshots Guide)

根据 uTools 插件市场发布要求，**插件应用截图最多可上传 8 张**，支持在后台拖动调整展示顺序。

优秀的宣传截图能够让审核人员快速理解插件价值，更能大幅提升用户在插件市场的安装转化率。

---

## 📐 截图设计规范与尺寸建议

| 参数项 | 推荐标准 | 说明 |
| :--- | :--- | :--- |
| **推荐分辨率** | `1280 × 800` (16:10) 或 `1920 × 1080` (16:9) | 保持高清高像素密度，字体清晰锐利 |
| **图片格式** | `PNG` (推荐) 或 `JPG` | PNG 无损压缩，黑色渐变过渡更细腻 |
| **单张大小** | `< 2MB` | 保证在市场内加载迅速 |
| **视觉基调** | **Raycast 沉浸式暗黑风格** | 配合插件自带的 `#07080a` 暗黑主题，保持现代、极客质感 |
| **图文排版** | 顶部保留简明加粗主标题 + 辅助副标，下方居中放置主操作界面 | 突出核心痛点与功能收益 |

- **取景画面**：
  - uTools 插件主界面（`index.html`）。

  - 分享列表展示几个预设的分享项。
- **重点传达**：极简现代的 Raycast 风格界面、清晰明了的状态反馈。

### 📸 截图 05：整目录层级浏览 · 无需打包直接下载
- **文件命名**：`05-folder-browsing.png`

- **副标题**：告别繁琐的压缩与解压缩，文件夹直接在浏览器层级穿透
- **取景画面**：

### 📸 截图 06：反向双向互传 · 安全文件回传上传
- **文件命名**：`06-bidirectional-upload.png`

### 📸 截图 07：临时公网穿透 · 打破局域网边界
- **文件命名**：`07-cloudflare-tunnel.png`
- **主标题**：**临时公网穿透 · 无公网 IP 也能异地大文件互传**
- **副标题**：内置 Cloudflare Quick Tunnel 穿透通道，一键生成临时安全链接
- **取景画面**：
